## 3. Issues the review did not raise (found in this cross-check)

1. **Log timestamps are approximate.** Several clock times in `RESEARCH_LOG.md` are my estimates and don't match git
   (for example, mechanism results are logged as "20:35" but were committed at 19:37). **Git commit times are the
   authoritative record.** A note is added to the log.
2. **Few post-shift positives.** The Elliptic after-shift finding rests on **169 illicit transactions** (steps 43–49),
   against 914 in 35–42. The bootstrap intervals reflect this, but the base is thin.
3. **Multiple comparisons.** The core experiment compared 4 stress tests across up to 7 windows. The after-shift
   pattern appeared in the 2 windows containing the shift, with no multiplicity correction. This is another reason to
   treat it as a lead.
4. **The forecast arm was starved.** The 8 drawable motif concepts appear in only 0–73 pre-2017 works. So "the forecast
   didn't beat random pairs" may reflect too little literature on the targets, not a failure of forecasting in principle.
5. **The mechanism worlds use the same motif generators as the stress tests.** H-match is close to built in for SB.
   The informative parts are W0 (recent data wins) and the camouflage result. This is already stated in
   `docs/results/mechanism.md`.
